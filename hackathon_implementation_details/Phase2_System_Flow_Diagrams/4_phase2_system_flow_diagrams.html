Key Decision Points

✓ Auto-Resolve Path

Trigger: Confidence > 0.85 AND LLM-judge score ≥ 3.5

Action: Send resolution to UserProxy → Close ticket

Success Rate: Target ≥ 25%

→ Department Route

Trigger: Confidence 0.60-0.85

Action: Assign to L1/L2 with suggested resolution

Success Rate: Target ≥ 60%

↑ Escalate Path

Trigger: Confidence < 0.60 OR multi-domain ticket

Action: Create context package → Route to L2/L3

Escalation Accuracy: Target ≥ 90%

Transition Guards & Actions

G1 Confidence Check

Guard: confidence_score >= threshold

Thresholds: Auto: 0.85, Dept: 0.60, Escalate: < 0.60

G2 Multi-Domain Check

Guard: is_multi_domain == true

Action: Force escalation regardless of confidence

G3 UserProxy Approval

Guard: user_confirmed == true

Required for: AUTO_RESOLVED state

A1 Log Routing Decision

Action: Write to routing_history table

Data: State change, confidence, reason

A2 Notify Agent

Action: Send email/Slack notification

Triggers: ASSIGNED, ESCALATED states

A3 Update Knowledge Base

Action: Re-embed accepted resolution

Triggers: CLOSED state (if feedback = accepted)
